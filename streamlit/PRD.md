## 1. 개요

### 1.1 배경
현재 앱은 React(TypeScript) 웹앱으로 만들어져 있고, PC에서 서버를 켜야만 휴대폰에서 접속할 수 있습니다. 이 앱을 **Python + Streamlit**으로 다시 만들어 **무료로 웹에 배포**하면,
- PC를 켜지 않아도 언제 어디서나 주소 하나로 접속할 수 있고,
- 코드를 Python 하나로 관리할 수 있으며,
- GitHub에 올리기만 하면 Streamlit Community Cloud가 자동으로 배포해 줍니다.

### 1.2 목표
1. 기존 앱의 **학습 기능(게임 규칙 R1~R10, 계산 문제 풀이과정 채점, 사진 풀이)** 을 그대로 옮긴다.
2. 기존 앱의 **디자인 콘셉트(진초록 + 형광 연두, 종이·테이프, 손그림 채점)** 를 Streamlit에서 가능한 범위로 재현한다.
3. **Streamlit Community Cloud**에 배포해 `https://<이름>.streamlit.app` 주소로 접속하게 한다.

### 1.3 범위 밖 (이번 버전에서 하지 않음)
- 회원가입·로그인 (v2에서 검토)
- AI 서술형·사진 자동 채점 (v2)
- 앱 스토어 출시

## 2. 기존 기능 유지 (게임 규칙)

| # | 규칙 | Streamlit 구현 방법 |
|---|---|---|
| R1 | 난이도 상·중·하 | 난이도 카드 3개 (`st.button` + CSS) |
| R2 | 기출문제 내 출제 | 기존 61문항을 `questions.json`으로 옮겨 사용 |
| R3 | 하: 빈칸 객관식 | 빈칸마다 4지선다 `st.pills` (또는 `st.radio` 가로 배치) |
| R4 | 중: 빈칸 주관식 | 빈칸마다 `st.text_input` |
| R5 | 상: 전체 주관식 | `st.text_area` + 키워드 채점 + 자가 채점 버튼 |
| R6 | 정답/오답 즉시 피드백 | 제출 직후 채점 결과 표시 + 손그림 ⭕/△/✕ + 테이프 떼기 |
| R7 | 정답 공개 후 해설 화면 | 모범답안·해설 영역 |
| R8 | 해설에 연상 암기 꿀팁 | 테이프로 붙인 노란 메모지 스타일 |
| R9 | 최종 완료 후 오답노트 | 결과 화면 → 오답노트 화면 |
| R10 | 카테고리 선택 후 3·2·1 | `st.empty()` 자리에 숫자를 1초 간격으로 바꿔 표시 |

### 2.1 계산 문제 (기존과 동일)
- 풀이과정 단계(steps)와 최종값을 함께 채점 (허용 오차 ±0.1%)
- 난이도 하·중: 풀이식의 중간값·최종값이 빈칸. 앞 단계 정답이 뒤 단계 식에 보이지 않도록 ①②로 가림
- 난이도 상:
  - **풀이 입력**: 풀이 속 숫자를 뽑아 단계별 중간값과 대조 (CO2·CH4 같은 화학식 숫자는 제외)
  - **📷 종이 풀이 사진**: `st.camera_input`(바로 촬영) 또는 `st.file_uploader`(갤러리) → 최종값 입력 → 단계별 셀프 체크
- 판정: 최종값 정답 + 풀이 단계 75% 이상 = 정답, 둘 중 하나만 = 부분 정답

### 2.2 오답노트 (기존과 동일)
- 틀린 문제·부분 정답 자동 저장, 정답이어도 "헷갈렸어요" 수동 저장
- 연속 2회 정답 시 졸업, 수동 졸업·복원·삭제
- 탭: 복습 중 / 졸업 / ⭐ 꿀팁 즐겨찾기
- 필터: 카테고리, 정렬: 최근 틀린 순 / 많이 틀린 순
- "오답만 다시 풀기" → 난이도 선택 → 3·2·1 → 풀이

## 3. 화면 구성

Streamlit은 화면 이동 대신 `st.session_state["screen"]` 값으로 보여줄 화면을 바꿉니다.

| ID | 화면 | 주요 요소 |
|---|---|---|
| S01 | 홈 | 제목 "온실가스관리기사 실기 준비", 정답률 원형 그래프, 오늘/풀어본 문항/복습할 오답, 학습 시작, 오답노트 |
| S02 | 난이도 선택 | 하·중·상 캡슐 카드 (01·02·03 번호) |
| S03 | 카테고리 선택 | 원형 테이프 스티커 10개 (전체 랜덤 + 9개) |
| S04 | 카운트다운 | 3 → 2 → 1 → START! |
| S05 | 문제 풀이 | 진행 바, 기출 회차, 문제, 난이도별 입력 |
| S06 | 채점 결과 | 테이프 떼기로 정답 공개, 손그림 채점 표시, 자가 채점(상) |
| S07 | 해설 | 모눈종이 모범답안·해설, 꿀팁 메모지, 즐겨찾기 |
| S08 | 결과 요약 | 점수, 문항별 ⭕/△/✕ 캡슐 목록, 펼쳐서 해설 보기 |
| S09 | 오답노트 | 탭, 필터, 다시 풀기, 졸업·삭제 |
| S10 | 설정 | 세트당 문항 수(5/10/20), 효과음, 데이터 초기화 |

## 4. 디자인

### 4.1 테마 (`.streamlit/config.toml`)
```toml
[theme]
base = "dark"
primaryColor = "#b6fe00"
backgroundColor = "#0b4a09"
secondaryBackgroundColor = "#013000"
textColor = "#f7f3e8"
```

### 4.2 재현 방법
| 디자인 요소 | 구현 방법 | 난이도 |
|---|---|---|
| 진초록 + 형광 연두 | `config.toml` 테마 + 전역 CSS | 쉬움 |
| Black Han Sans 제목 글씨 | 전역 CSS에서 Google Fonts `@import` | 쉬움 |
| 구겨진 종이·모눈종이 질감 | CSS 배경(SVG 노이즈, 격자선) | 쉬움 |
| 캡슐 카드·마스킹테이프 | `st.html`로 HTML/CSS 조각 출력 | 보통 |
| 원형 테이프 스티커 (카테고리) | SVG 그림 + 그 아래 `st.button` 겹치기 | 보통 |
| 손그림 ⭕/△/✕, 밑줄 | SVG + CSS 그리기 애니메이션 | 보통 |
| 테이프 떼기 효과 | `st.html` 안의 CSS 애니메이션 (자동 재생) | 보통 |
| 3·2·1 카운트다운 | `st.empty()` + 1초 간격 갱신 | 쉬움 |

### 4.3 Streamlit 디자인 제약 (미리 알아둘 점)
- **화면 전체 다시 그리기**: 버튼을 누를 때마다 파이썬 코드가 처음부터 다시 실행됩니다. 애니메이션이 다시 재생되지 않도록, 애니메이션은 "방금 제출했을 때"에만 출력합니다.
- **버튼 모양 제한**: `st.button` 자체는 원형 스티커처럼 만들기 어렵습니다. 그림은 HTML로 그리고, 누르는 동작은 그 아래 버튼이 맡습니다. CSS로 투명하게 겹치는 방식도 검토합니다.
- **탭해서 테이프 떼기**: HTML 안에서 누른 동작은 파이썬으로 전달되지 않습니다. 그래서 테이프 떼기는 **자동 재생**으로 하고, 누를 필요가 없게 합니다.
- **반응 속도**: 누를 때마다 서버를 거쳐서 React 앱보다 0.2~0.5초쯤 느릴 수 있습니다.

## 5. 데이터 저장

Streamlit 서버는 화면 상태를 기억하지만, **새로고침하거나 앱이 잠들면 사라집니다**. Community Cloud는 서버에 파일을 오래 저장할 수도 없습니다. 그래서 학습 기록 저장 방식을 정해야 합니다.

| 방식 | 장점 | 단점 |
|---|---|---|
| A. `st.session_state`만 사용 | 가장 간단 | 새로고침하면 기록이 모두 사라짐 |
| **B. 브라우저 저장소 (추천)** | 로그인 없이 기기별로 기록 유지, 기존 앱과 같은 방식 | 외부 컴포넌트(`streamlit-local-storage` 등) 필요, 기기·브라우저가 바뀌면 기록이 따로 저장됨 |
| C. 외부 DB (Supabase·Google Sheets) | 기기를 바꿔도 기록 유지 | 닉네임·로그인 필요, DB 설정·키 관리 필요 |

- **MVP는 B안**: 브라우저 저장소에 오답노트·통계·즐겨찾기·설정을 JSON으로 저장합니다.
- **백업**: 설정 화면에 "기록 내보내기 / 불러오기(JSON 파일)"를 둬서 기기를 바꿀 때 옮길 수 있게 합니다.
- **사진**: 긴 쪽 900px JPEG로 줄여서 오답노트에 저장합니다. 저장공간이 부족하면 사진 없이 저장합니다. 사진은 서버에 따로 보관하지 않습니다.
- **v2**: 여러 기기에서 같이 쓰려면 C안(Supabase + 간단한 로그인)으로 바꿉니다.

### 5.1 데이터 구조 (기존과 동일, JSON)
```json
{
  "wrongNotes": { "Q2020-4-12": { "wrongCount": 2, "consecutiveCorrect": 0, "lastWrongAt": "...", "lastUserAnswer": "...", "graduated": false, "photo": "data:image/jpeg;base64,..." } },
  "stats": { "Q2020-4-12": { "tries": 3, "correct": 1, "last": "..." } },
  "favTips": ["Q2021-2-01"],
  "settings": { "count": 10, "sound": true }
}
```

## 6. 기술 구성

### 6.1 폴더 구조
```
streamlit/
├── PRD.md
├── app.py                  # 진입점: 화면 전환(router)
├── requirements.txt
├── .streamlit/
│   └── config.toml         # 테마
├── data/
│   ├── questions.json      # 기출 61문항 (React 앱 데이터에서 변환)
│   └── categories.json
├── core/
│   ├── grading.py          # 채점 (정규화, 빈칸, 키워드, 계산 단계)
│   ├── quiz.py             # 세트 구성, 보기 생성, 계산 빈칸 변환
│   └── storage.py          # 브라우저 저장소 읽기/쓰기, 오답노트 규칙
├── ui/
│   ├── styles.py           # 전역 CSS (글꼴, 종이, 테이프, 애니메이션)
│   ├── components.py       # 스티커, 캡슐, 손그림, 테이프 떼기 HTML 조각
│   └── screens/            # home, difficulty, category, countdown, quiz, result, wrong_notes, settings
└── tests/
    └── test_grading.py     # 61문항 정답·오답·누출 검사 (기존 검사 이식)
```

### 6.2 라이브러리
| 용도 | 라이브러리 |
|---|---|
| 웹 화면 | `streamlit` (1.4x, `st.pills`·`st.html`·`st.camera_input` 사용) |
| 브라우저 저장소 | `streamlit-local-storage` (또는 동급 컴포넌트) |
| 사진 축소 | `Pillow` |
| 테스트 | `pytest` |

### 6.3 기존 로직 이식
- **문제 데이터**: `app/src/data/questions.ts` → `questions.json` 변환 스크립트로 한 번 옮김. 이후 JSON이 원본.
- **채점 규칙**: `app/src/lib/grading.ts`를 `grading.py`로 그대로 옮김
  - 정규화(공백·대소문자·쉼표·아래첨자 무시), 동의어, 순서 무관(unordered) 빈칸
  - 키워드 통과 기준 70%, 계산 단계 통과 기준 75%, 숫자 허용 오차 0.1%
- **검증**: 기존에 돌린 검사(정답 입력 → 정답, 오답 보기 → 오답, 보기 4개, 계산 빈칸 정답 누출 없음)를 `pytest`로 옮겨 똑같이 통과해야 함.

## 7. 배포

### 7.1 Streamlit Community Cloud (무료)
1. GitHub에 저장소를 만들고 `streamlit/` 폴더를 올림
2. https://share.streamlit.io 에 GitHub 계정으로 로그인
3. **Create app** → 저장소·브랜치 선택, Main file path에 `streamlit/app.py` 입력
4. 앱 주소 정하기 (예: `ghg-silgi.streamlit.app`) → **Deploy**
5. 이후 GitHub에 코드를 올리면 자동으로 다시 배포됨

### 7.2 운영 시 알아둘 점
- **잠자기**: 무료 앱은 한동안 아무도 접속하지 않으면 잠듭니다. 다음 접속 때 깨우는 버튼이 나오고, 다시 켜지는 데 수십 초 걸릴 수 있습니다.
- **공개 범위**: 기본은 주소를 아는 누구나 접속할 수 있습니다. 혼자 쓰려면 앱 설정에서 이메일로 접근을 제한합니다.
- **용량**: 무료 서버 자원이 제한적이라 큰 이미지를 서버에 오래 두지 않습니다(사진은 브라우저에 저장).

## 11. 미결 사항 (Open Questions)
1. **학습 기록 저장 방식**: 추천은 브라우저 저장소(B안). 여러 기기에서 같은 기록이 필요하면 C안(로그인 + DB)
2. **React 앱 유지 여부**: Streamlit 버전 완성 후 기존 `app/`(React)을 계속 둘지, Streamlit만 쓸지
3. **공개 범위**: 누구나 접속 / 본인만 접속(이메일 제한)
4. **앱 주소 이름**: 예) `ghg-silgi.streamlit.app`
5. **효과음**: Streamlit에서는 소리 재생이 제한적이라 빼도 되는지
